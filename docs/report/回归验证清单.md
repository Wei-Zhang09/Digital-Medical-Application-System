## 八、复跑方式

```bash
# 1) 起后端（当前 jar）
cd backend/target && java -jar medicai-1.0-SNAPSHOT.jar --server.port=8081

# 2) 起前端（指向 8081）
cd frontend
export PATH="$PWD/../.dev/node22/PFiles64/nodejs:$PATH"
VUE_APP_API_BASE="http://127.0.0.1:8081/api" npx vue-cli-service serve --port 9093

# 3) 跑回归脚本（需先开 Chrome 调试端口 9222）
NODE_PATH=".dev/tools/node_modules" node scripts/e2e/regression.js
```

> 回归脚本已入库：`scripts/e2e/regression.js`（正式版，非临时脚本）。

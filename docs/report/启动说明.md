# 启动说明（自己跑起来）

> 两种方式：**开发态**（9092，改代码热更新）和**部署态**（80，Nginx，答辩演示用）。
> 环境已经配好，下面命令都在项目根目录 `D:\HermesWorkSpace\Digital Medical Application System` 执行。

## 一、开发态：三条命令（推荐）

三个终端各跑一条，顺序不能反。

### 终端 1：数据库（二选一）

**用你本机的 MySQL09（3306）**：先启动服务，再导入一次库

```text
1) 启动服务：services.msc 里启动 MySQL09，或管理员命令行 net start MySQL09
2) 双击 scripts\导入数据库到本机MySQL.bat，按提示输一次 root 密码
3) 之后后端默认就连 3306，不用改配置
```

**用项目自带的 3307 实例**（隔离，不碰 MySQL09）

```bash
bash scripts/db.sh start        # 或双击 scripts\启动数据库.bat
```

看到 `MySQL 已启动：127.0.0.1:3307` 即可。数据已经在库里（17 张表、种子数据），不用重新导入。
用这个方案时后端要带 `DB_PORT=3307`（`dev.sh` 已自动处理；IDEA 里需在 Run Configuration 加环境变量）。

### 终端 2：后端

```bash
source scripts/env.sh          # 把项目内的 Node 22、mvn.cmd、mysql 客户端加进 PATH
cd backend
mvn clean package -DskipTests  # 首次或改过 Java 代码才需要，约 40 秒
cd target
java -jar medicai-1.0-SNAPSHOT.jar
```

看到 `Started MedicalApplication in 7.x seconds` 就是起来了。这个窗口不要关，**也不要拖选控制台文字**（Windows 快速编辑会卡住输出）。

验证：浏览器打开 `http://127.0.0.1:8080/swagger-ui.html/`（末尾斜杠必须写）。

### 终端 3：前端

```bash
source scripts/env.sh
cd frontend
npm run serve
```

首次需要 `npm install`（约 5 分钟）。看到 `App running at: http://localhost:9092` 后打开：

```text
http://localhost:9092/#/user/login
```

**账号**：管理员 `admin_1` / `123456`　医师 `王小明4125` / `123456`

> 前端必须用项目内的 Node 22.13（系统装的是 26.x，Vue CLI 5 + webpack 5 在 26 上不一定稳）。
> `source scripts/env.sh` 已经把 `.dev/node22` 放到 PATH 最前面，`node -v` 应显示 `v22.13.0`。

## 二、开发态：一键（省事版）

```bash
bash scripts/dev.sh            # 起数据库 + 后端，然后前台跑前端
bash scripts/dev.sh backend    # 只起数据库 + 后端
bash scripts/dev.sh frontend   # 只起前端（后端已在跑时用）
bash scripts/dev.sh status     # 看三个端口的状态
bash scripts/dev.sh stop       # 停前端与后端（数据库保留）
```

`dev.sh` 会自己判断：库没起就起库、jar 不在就打包、端口被占就跳过。后端日志在 `backend/target/app.log`。

## 三、部署态：80 端口（答辩演示用）

```bash
bash scripts/deploy.sh         # 打包 + 部署到 Nginx + 启动后端与 Nginx
bash scripts/deploy.sh stop    # 全部停掉
```

打开 `http://127.0.0.1/#/user/login`（地址里没有 9092）。

前置条件：`.dev/nginx/nginx-1.20.1` 已解压（`docs/report/部署说明.md` 第 2 步），80 端口没被占用。

## 四、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `mvn` 报 `classworlds` 找不到 | 这是 MSYS 下 bash 版 mvn 的问题。用 `source scripts/env.sh`（里面把 `mvn` 指向了 `mvn.cmd`） |
| `node -v` 显示 26.x | 没 source env.sh；或 PATH 顺序被别的工具改了 |
| 登录一直转圈 | 后端没起来，或前端 `.env.development` 里的地址不对（应为 `http://localhost:8080/api`） |
| 登录提示用户名或密码错误 | 重跑 `mysql ... digital_medical_application_system < sql/reset_pwd.sql` 把口令重置为 123456 |
| 药品图片显示占位图标 | 运行目录 `uploads/` 里没有图：`bash scripts/seed-images.sh` |
| 端口被占 | `bash scripts/dev.sh stop`；仍占用就 `netstat -ano | grep ":8080"` 找到 pid 后结束 |
| 前端编译报 `ERR_OSSL_EVP_UNSUPPORTED` | Node 版本不对，确认用的是 `.dev/node22` 里的 22.13 |
| 控制台日志卡住、接口无响应 | 后端窗口被选中了文字，按一下回车取消选中 |

## 五、目录速查

| 路径 | 内容 |
| --- | --- |
| `backend/` | Spring Boot 工程（`target/medicai-1.0-SNAPSHOT.jar` 是产物） |
| `frontend/` | Vue 工程（`npm run serve` 开发，`npm run build` 出 dist） |
| `sql/` | `digital_medical_application_system.sql` 建库脚本、`sale_ext.sql` 地图扩展、`reset_pwd.sql` 口令重置、`image_url_relative.sql` 图片地址 |
| `scripts/` | `env.sh` 环境、`db.sh` 数据库、`dev.sh` 开发启动、`deploy.sh` 部署、`seed-images.sh` 种子图 |
| `deploy/nginx.conf` | Nginx 站点配置 |
| `docs/report/` | 报告、测试文档、答辩材料（docx/pptx 由脚本生成） |
| `.dev/` | 本地 Node 22、MySQL 数据目录、Nginx（不进版本库） |
